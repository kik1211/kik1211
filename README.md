## 🛠️ Featured Projects

### 1. [N.O.V.A. — VLC Secure Access & Autonomous Docking](https://github.com/kik1211/nova-vlc-secure-docking)
> **ESP32-S3 • C++ • Goertzel DSP • Edge Impulse 1D-CNN • PN532 NFC • Stepper Docking**  
ESP32-S3 research prototype combining NFC card verification with Visible Light Communication (VLC) for dual-factor physical access control. Implements an esp_timer hardware ISR, parallel Goertzel IIR DFT frequency evaluation (=10, 20, 30$), Edge Impulse 1D-CNN classifier wrapper (\text{ B}$ tensor arena), and a 2-phase autonomous optical stepper alignment platform.

### 2. [Protocol Monitor IP Core](https://github.com/kik1211/Protocol-Monitor-IP)
> **Verilog HDL • Xilinx Vivado • ZedBoard Zynq-7000 • Valid/Ready Handshakes • Hardware Verification**  
Synthesizable Verilog FPGA IP core for real-time, passive monitoring of Valid/Ready streaming data interfaces. Features real-time protocol assertion violation detection (4 failure modes), cycle-accurate transaction latency measurement (min/max/last), sliding-window throughput telemetry, Xilinx ILA debug hooks, and a self-checking testbench.

### 3. [NeuroFrost — Temporal Infrared Thermometry Inference](https://github.com/kik1211/NeuroFrost-Inference)
> **ESP32 / SAMD21 • MLX90614 IR Sensor • Edge Impulse C++ SDK • TensorFlow Lite Micro**  
Embedded TinyML proof-of-concept for early cerebrovascular risk screening using temporal in-ear infrared thermometry on an MLX90614 sensor (I2C address 0x5A) with on-device neural network classification.

### 4. [Agentic Medical Claims Automation Platform](https://github.com/kik1211/agentic-medclaims-automation)
> **TypeScript • React 18 • Express • Docker • Redis • BullMQ • Gemini LLM API**  
Full-stack hospital insurance claim processing platform featuring automated OCR, LLM-based clinical structuring, ICD-10-CM/CPT auto-coding, async Redis/BullMQ message queues, and Dockerized backend services.

### 5. [QwenQuest MR — Spatial Wave Shooter](https://github.com/kik1211/QwenQuest-MR-Shooter)
> **Unity 6 • Meta Quest 3 • C# • Arduino KWS • Python LLM Relay • WebSockets**  
Mixed Reality spatial wave shooter built with Unity 6, Meta Quest 3 Passthrough (OpenXR/MRUK), an Arduino Uno Q voice hardware device running keyword-spotting (KWS), and a local Python Qwen LLM AI commentary relay. Built at the Snapdragon Multiverse Hackathon Finale.

### 6. [PDF Processing Suite](https://github.com/kik1211/pdf-processing-suite)
